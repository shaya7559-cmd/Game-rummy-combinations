# רמי קומבינציות — ניהול ניקוד

אפליקציית ווב לטלפון שמנהלת את הניקוד במשחק רמי קומבינציות: הזנת נקודות לאורך כל משחק, טבלה, היסטוריה ודוחות.
היא בנויה מ-HTML, CSS ו-JavaScript רגילים, בלי שלב בנייה, ומתארחת ב-GitHub Pages.
נקודת ההתחלה היא עותק של אפליקציית רמי 51 (מאגר `Game-rummy51`).

> **מצב:** האפליקציה באוויר בכתובת <https://shaya7559-cmd.github.io/Game-rummy-combinations/>. כל הבדיקות ב-`tests.html` עוברות.

**מילים:** **טורניר** = קבוצת משתתפים שמשחקת כמה משחקים. **משחק** = יד אחת, מהחלוקה ועד שמישהו מנצח. אין שום רמה ביניהם (אין ערב, סבב או תור).

## הכללים שהאפליקציה מנהלת
- **מסך הטורניר:** שורה לכל משתתף: מקום, שם, הנקודות במשחק הנוכחי, הניקוד הכללי בטורניר, וכפתורי **+** ו-**−**. השורות ממוינות לפי הניקוד הכללי, והוא כולל את המשחק שבאמצע, כך שהמקומות מתחלפים תוך כדי המשחק.
- **נקודות במהלך משחק:** כל משתתף צובר נקודות כמה פעמים במשחק. **−** מוריד נקודות שהוזנו בטעות, עד מה שנרשם לו במשחק הזה. כל רישום נשמר בנפרד, ואפשר לתקן או למחוק אותו גם במסך סיום המשחק.
- **סוף משחק:** המנצח הוא **האחרון שקיבל נקודות**, ולכן האפליקציה לא שואלת (אפשר לשנות אם צריך). המנצח שומר את מה שצבר. מכל השאר מחסירים את הנקודות שנשארו ביד, ומי שלא ירד מקבל ‎-70 (מסומן לבד למי שאין לו נקודות במשחק).
- **אין** מכפילים, אין גלוק ואין פריש. אין מחלק.
- **סוף הטורניר:** אין מספר משחקים קבוע. מסיימים מתי שמחליטים, או משאירים פתוח וממשיכים בפעם הבאה. מנצח מי שצבר **הכי הרבה** נקודות; בשוויון, מי שניצח ביותר משחקים; ואם גם זה שווה, הניצחון משותף. משחק פתוח שלא הסתיים לא נספר. אפשר להמשיך טורניר שהסתיים.
- **סיכומים:** כלל הנקודות, הניצחונות והמשחקים של כל משתתף מכל הטורנירים; הניצחונות והנקודות בכל טורניר; ושיאים.

## שמירה בטלפון
שתי האפליקציות נמצאות תחת `shaya7559-cmd.github.io` ולכן חולקות את האחסון בדפדפן.
האפליקציה הזו שומרת תחת המפתחות `rummycombos.v2` ו-`rummycombos.github`, כדי לא לדרוס את הנתונים של רמי 51.
הנתונים של הגרסה הראשונה (`rummycombos.v1`, ערבים) מומרים פעם אחת לטורנירים: כל משחק של ערב הופך למשחק בטורניר שלו. העותק הישן נשאר בטלפון כמו שהוא.

## עדכון האתר
- המאגר הציבורי `shaya7559-cmd/Game-rummy-combinations` מפורסם ב-GitHub Pages מהענף `main`, מהתיקייה הראשית (**Settings → Pages → Deploy from a branch → `main` / `(root)`**).
- כל שינוי עולה לאתר כך: ב-GitHub Desktop ‏**Commit to main** ואז **Push origin**. אחרי דקה או שתיים, בלשונית **Actions** של המאגר מופיע ✓ ירוק ליד `pages build and deployment`, והאתר מעודכן.

## שמירת הטורנירים בגיט
הטורנירים נשמרים במאגר נתונים **נפרד ופרטי**: `shaya7559-cmd/RummyCombos-data`, קובץ לכל טורניר ב-`data/tournaments/`, כולל המשחק שבאמצע.
הקבצים של הגרסה הראשונה (`data/games/`, `data/current.json`, `data/tournaments.json`) כבר לא בשימוש.
- עותק שלו במחשב נמצא ב-`ClaudeWorkFolder\RummyCombos-data`, ליד התיקייה של האפליקציה ולא בתוכה. הוא מתעדכן ב-GitHub Desktop עם **Fetch origin** ואז **Pull origin**.
- לאפליקציה יש Fine-grained token שיש לו גישה **רק** למאגר הזה, עם ההרשאה **Contents: Read and write**.
- בכל טלפון, פעם אחת: **גיט וגיבוי** ← מזינים `shaya7559-cmd/RummyCombos-data` ואת הטוקן ← **חבר ובדוק**.
